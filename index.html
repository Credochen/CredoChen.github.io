关于本站

技术说明

所有页面都是单个 HTML 文件：样式内联、插画是 SVG、不引用任何外部图片或字体，所以拔掉网线也能正常打开，也可以直接发给别人。

本站用 GitHub Pages 托管，内容随仓库更新。

内容说明

「小小读者导读」是故事梳理与阅读辅助，不是原文节选；涉及沉重内容时会在「给家长」一段明确标注。历史档案类页面的史料来源与分歧说法，写在每篇末尾的「史料说明」里。

如果发现史实错误或表述问题，欢迎提 Issue 指正。
